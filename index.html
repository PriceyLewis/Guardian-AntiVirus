Install the real app

On Debian, Ubuntu, Fedora, Arch or openSUSE, one command installs ClamAV, its daemon and Guardian:

curl -fsSL https://raw.githubusercontent.com/PriceyLewis/Guardian-AntiVirus/main/install.sh | sh

Or download Guardian.flatpak from the releases page and run flatpak install --user Guardian.flatpak. The Flatpak includes its own ClamAV.
