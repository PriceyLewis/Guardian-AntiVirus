# Guardian Antivirus — v1.0.0 Portfolio Release

**Release date:** 20 September 2026  
**Status:** Recruiter-ready portfolio release

Linux desktop security portfolio application integrating PySide6, ClamAV, SQLite, monitoring, quarantine and a safe browser simulation.

## Release highlights

- Quick, Home and Custom scan flows
- ClamAV daemon integration with CLI fallback
- Filesystem monitoring
- Quarantine, restore and overwrite protection
- Persistent scan history and defensive settings behaviour

## Verification completed

- Pytest regression suite passes.
- Interactive browser demo workflow passes after native tests.
- Browser journeys verify simulated detections, quarantine/restore, settings and quick scans.
- Mobile demo layout is checked for overflow and runtime errors.

## Portfolio scope

This release is intentionally presented as a portfolio/demo build. It demonstrates implemented engineering work and verified user journeys without claiming production deployment, certification, commercial readiness or operational guarantees beyond the documented scope.

## Reviewer path

Start with the repository README, use the linked live demo where available, then review the source and automated tests for implementation evidence.
